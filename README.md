### Proyek Unggulan

- **Kostan BagaskaraAP-Dev (Property Management System)**
  - Sistem manajemen kost modern berbasis Full-Stack (Node.js, Express, SQLite, Responsive UI).
  - Dilengkapi modul katalog kamar mandiri berbasis SVG, kalkulator sewa otomatis, sistem helpdesk ticketing pelaporan kerusakan, dan panel analitik keuangan pengelola.
  - Repositori: [BagaskaraAP-Dev/kostan-bagaskaraap-dev](https://github.com/BagaskaraAP-Dev/kostan-bagaskaraap-dev)
  - Live Demo: [bagaskaraap-dev.github.io/kostan-bagaskaraap-dev](https://bagaskaraap-dev.github.io/kostan-bagaskaraap-dev/)

- **Mooncrust AI**
  - Aplikasi antarmuka percakapan kecerdasan buatan lokal berbasis model bahasa besar (LLM).
  - Integrasi runtime Node.js, pemrosesan prompt aman, dan penyajian antarmuka web responsif.
  - Repositori: [BagaskaraAP-Dev/MOONCRUST-AI-BELUM-FINAL](https://github.com/BagaskaraAP-Dev/MOONCRUST-AI-BELUM-FINAL)
